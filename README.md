# Менеджер рассылок.

Веб-приложение на Django, которое позволяет пользователям управлять рассылками сообщений 
для клиентов. Приложение включает функциональность для создания, просмотра, 
редактирования и удаления рассылок, а также отправки сообщений по требованию.

# Инструкция по установке и использованию разработанного функционала приложения
1. Клонируйте репозиторий:
```
git clone https://github.com/4usnok/Project_4_Mailing_manager.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
